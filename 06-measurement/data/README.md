# Data exports

Drop CSV or Excel exports here (Google Analytics, Search Console, email platform, event platform, CRM).

`.csv` and `.xlsx` files in this folder are **not uploaded to GitHub**, because exports can contain personal data. The marketing analyst reads them locally and writes anonymised results to `../reports/`.

Name files `YYYY-MM-<source>.csv`, e.g. `2027-01-search-console.csv`.
