# KPI definitions

One definition per KPI, so everyone counts the same way.

| KPI | Definition | Source | Reported |
|---|---|---|---|
| Website visitors | Unique users per month | `<Google Analytics>` | Monthly |
| Organic search clicks | Clicks from Google search | `<Search Console>` | Monthly |
| AI answer mentions | Times we're named when set questions are asked in ChatGPT, Perplexity and Gemini | Manual check of `<10>` set questions | Monthly |
| Email subscribers | Total active subscribers | `<email platform>` | Monthly |
| Event registrations | Sign-ups per event | `<event platform>` | Per event |
| Event attendance rate | Attendees ÷ registrations | `<event platform>` | Per event |
| Leads | `<define: e.g. booked call or form enquiry>` | `<CRM>` | Monthly |
| Customers won | New paying customers | `<CRM>` | Monthly |
