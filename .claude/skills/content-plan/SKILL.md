# Content plan (one month)

## Steps

1. **Inputs.** Read the content manager's required files (see the agent). Also read:
   - The latest report in `06-measurement/reports/` (what performed, what to do more of).
   - `03-campaigns/` and `03-campaigns/events/` for the month: every live campaign and the month's event need supporting content.
   - Any `content-request.md` in event folders.
2. **Questions.** List 15–20 real questions the ideal customer asks, from `library/customers/` and web research (Google "People also ask", forums, Reddit, competitor FAQs). Note the source of each.
3. **Gaps.** Remove questions already answered in `library/content/past-blogs/`. For any that are answered but out of date, plan a refresh instead.
4. **Choose.** Pick the pieces for the month (default: 4 articles + 1 refresh + event support content). Balance the pillars in `content-pillars.md`. Prioritise questions close to buying, and topics that support the month's event.
5. **Calendar.** Add one row per piece to `04-content/content-calendar.md`: publish date, title, pillar, format, channel, target question, owner, status `idea`.

## Output

A short summary table (piece, target question, why now, pillar), then the calendar rows you added. Say which piece to brief first.
