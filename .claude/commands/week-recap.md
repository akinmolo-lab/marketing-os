| Section | Content |
|---|---|
| **Shipped** | Content published, campaign milestones, event progress |
| **Numbers** | Only figures from real data, with source |
| **Slipped** | What didn't happen and why |
| **Next week** | Top 5, ranked, each tied to a quarterly goal |
| **Next event** | Days to go, registrations so far (if known), what's due |
