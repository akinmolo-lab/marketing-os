Use the `marketing-analyst` agent to update the ICP.

1. Read everything in `library/customers/` (`icp-data/`, `interviews/`, `reviews.md`). If raw exports exist in `library/customers/raw/`, read them locally and summarise them anonymously into `library/customers/icp-data/YYYY-MM-DD-summary.md`. Never copy names, emails or phone numbers.
2. Compare with `01-foundation/ideal-customer.md`.
3. Propose changes as a table: field, current, proposed, evidence (file). Include new questions customers ask, new objections and new phrases in their own words.
4. After I say yes, update the file and its "Last updated" date.
