File a finished campaign in the library: $ARGUMENTS

1. If it's in `03-campaigns/`, use that folder. If it's an older campaign, ask me for the brief, results and where the poster files are.
2. Create `library/campaigns/YYYY-MM-<short-name>/` with `brief.md`, `results.md` and the poster or ad images. Check each image is under 10 MB; if bigger, ask me for a smaller export.
3. Make sure `results.md` has numbers (with source), what worked, what didn't and lessons. Never invent a number: mark gaps as `[MISSING]` and ask me.
4. Ask before moving or deleting the original folder in `03-campaigns/`.
